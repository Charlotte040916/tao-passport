# Roadmap

## Phase 1: Submission Scaffold

- Full-stack project structure
- Demo passport UI
- Express API endpoints
- PostgreSQL schema
- Documentation and CI

## Phase 2: Data Integrations

- Live Bittensor chain queries
- Wallet history indexing
- Validator and miner metrics
- Governance participation indexing
- GitTensor contribution ingestion

## Phase 3: Reputation Engine

- Versioned scoring models
- Signal provenance and audit views
- Abuse-resistant contribution weighting
- Community review and dispute workflows

## Phase 4: Ecosystem Distribution

- Public wallet pages
- Embeddable passport cards
- API keys and rate limits
- Vercel and Railway/Render deployment guides
